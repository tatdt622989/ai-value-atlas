# 公平排序 v3

規則更新日期：2026-09-20（不代表下方榜單快照已重新量測）。這是公開、可重現的推薦規則，不宣稱存在唯一客觀的「最划算」，也不把推薦分數稱為收益倍數。

## 兩個視角

- 綜合推薦：同領域能力 + 實際每美元 Token 可用量。
- 優惠倍率：已採用研究的 API 等值倍率；次數、tokens 和平台 credits 不放入金額欄。沒有金額倍率的方案仍保留價格、條件及来源。

全部研究與歷史數字保留可見。`dataStatus=historical`（停用、被替代或只從舊審核註記恢復的倍率）不參與推薦分數、效率百分位母體或目前價值排序，也不顯示最佳標示。原估算放在使用條件欄並標明未採用；這與僅超過複查期限而仍採用的 `review` 狀態不同。

混合模型套餐保留原模型標籤、倍率、研究依據及名次參考；沒有拆分用量時綜合分數為空，留在同一列表，不捏造 Token 數。價格、原始研究採納權重與觀測量不因演算法改版而改寫。

## 算法

每美元用量 E = 同使用情境的百萬 Token 數 / 實付美元。計算沿用明示的 80/20 輸入輸出情境、快取選項、限額、使用率及原始研究量。不同模型的 Token 並非等量成功任務，因此這只是可用量比較。

用量百分位 P：在同分類、同情境、未套用預算／搜尋／通路／速度／名次篩選的全部有效方案中，對不同 E 值去重；P=(小於 E 的值數 + 等於 E 的值數/2)/總數。年繳選項不影響校準池。方案新增或來源快照變更可以影響分数，但使用者篩選不能改變同一方案分數。原始研究 calculated 的用量可參與；estimate 的混合用量不推算。

能力百分位 Q=(N-r+0.5)/N；N 是來源完整有名次的榜單規模，不是本網站只映射到的模型數。r 採來源名次區間的保守端；沒有區間時採原名次。介面仍只顯示來源原名次。

推薦分數 = 100 × P^0.6 × Q^0.4。

60/40 是價值優先的產品偏好，不是數學證明的最佳權重。幾何加權要求兩個維度都有表現，極低能力不能單靠大量用量完全抵銷。原始點估計、信賴區間與測試版本均保留以供覆核。它不代表模型能力的實際倍率或成功任務數。

同一來源、同榜單版本、同日期和相同來源快照才可用於同類能力比較；不以其他來源或舊榜單補某個模型的空缺。不同 harness 名稱保留，僅在來源已正式放在同一榜單比較時使用其名次，不自行混合原始測試分數。

## 已知限制

- 訂閱使用量是指定使用情境；未用滿、同套餐共用額度與不同時窗不可相加。
- 混合模型套餐的單模型分配缺失，不能靠某個最強模型的排名推算整包都能使用它。
- 能力排行榜是模型／設定的參考，未直接量測每家轉售通路的工具與可靠性。
- 當前資料覆蓋不完整；未映射的正確版本仍需逐一核對，不自行視為低能力。
- 分數僅適合同一分類與情境，不應比較不同領域的 90 分與 70 分。
- 下一階段若有實際任務日誌，可改進為「每美元成功完成任務數」，納入重試、失敗與人工修正成本。
